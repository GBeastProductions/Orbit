# GUI Asset Library

Purpose: screen-level visual assets for title, song select, settings, and navigation.

Suggested contents:
- `backgrounds/`: subtle paper/noise/grid treatments and approved scene backplates.
- `panels/`: panel borders, dividers, tabs, and reusable frames.
- `icons/`: one consistent icon family, with SVG preferred.
- `textures/`: restrained grain, halftone, and optical-disc surface textures.
- `fonts/`: only fonts with documented redistribution rights; otherwise load from a licensed provider at runtime.

Do not dump whole asset packs here. Import only assets selected for a specific screen and list their provenance in `../CREDITS_AND_LICENSES.md`.
