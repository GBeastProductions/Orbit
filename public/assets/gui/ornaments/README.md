# ORBIT Graphic Motifs

Original, purpose-built SVG motifs for the ORBIT visual system. These are editable vector shapes, not generated raster illustrations. They use the shared palette: night #090A12, cyan #39D9E8, magenta #F044A4, violet #B18AFF, gold #F8C75E, and soft white #F3F1FA.

Use one motif at a time, at low contrast. The disc and orbit arcs reinforce the rhythm/turntable identity; the signal grid and corner brackets are secondary framing only. Do not scatter them as decoration or place them behind dense note patterns.
