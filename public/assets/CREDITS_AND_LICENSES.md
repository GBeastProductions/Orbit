## Import ledger

No third-party binary assets have been copied into this repository by this setup commit. The sources above have been researched and recorded; select individual files only after checking format, visual fit, and the exact license packaged with the download.

When importing, add one row per asset with creator, exact filename, original URL, license, local path, and modifications. Never remove original copyright/license notices from MIT-licensed code.
