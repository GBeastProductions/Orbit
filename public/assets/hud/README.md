# HUD Asset Library

Gameplay-only assets. Prioritize clarity at speed and on small screens.

- `judgments/`: PERFECT / GREAT / GOOD / MISS feedback treatments.
- `indicators/`: progress, accuracy, timing, combo and key-state indicators.
- `effects/`: hit flashes, streaks, trails, and restrained feedback overlays.
- `icons/`: gameplay-specific symbols.

All feedback must be readable without color alone and must not obscure notes or the playfield.
