# ORBIT HUD Asset Library

Use assets here for functional game information, not decoration. Keep score, combo, accuracy, song progress, and judgment feedback visually distinct. Judgments must never obscure incoming notes. The new beat-ring, beat-ticks, orbit-node, progress-track, score/combo frames, and judgment marks are original ORBIT-specific SVG vectors with transparent backgrounds and shared palette colors.

Legacy Lucide icons remain useful for small utility actions. Avoid treating the large generic crosshair set as the game's identity; ORBIT's visual language is orbital timing, not tactical targeting.
